# Technology Standards

Technology rules supplement the SQL layer and artifact standards. Select the actual execution target explicitly; do not infer it from the SQL syntax or the BI layer.

- `fabric/warehouse.md`: inherited Fabric Warehouse type and connection requirements.
- `serverless/`: reserved pending identification of the intended serverless product and approved rules.
- `sqlserver/`: reserved for approved SQL Server rules.

Fabric Warehouse rules do not automatically apply to other Fabric engines, Serverless, SQL Server, or Azure SQL. Reserved folders contain no active technology policy and are not registered as supported target routes.

General performance guidance belongs to a separate knowledge base. Approved indexing rules remain with the applicable layer or artifact standards.
